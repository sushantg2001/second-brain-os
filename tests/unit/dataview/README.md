`tests/fixtures/dataview/importer-0.5.68.json` is what Dataview's own importer (`parsePage`)
returns for the notes in it, serialized the way `dv.page()` returns it. It was generated by
running Dataview 0.5.68's code on each note with the list structure Obsidian reports written by
hand, so it shows how Dataview treats text on lines under a task, repeated fields, emoji dates
and links without a running Obsidian. `importer-contract.test.ts` holds the test fake
(`tests/fakes/fake-dataview.ts`) to it. When Dataview is upgraded, regenerate the file and run the
tests: a difference means the plugin's reading of Dataview needs a look.
