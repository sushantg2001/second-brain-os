# Third-party notices

The calendar and day planner interfaces are laid out after four Obsidian plugins. Some of their
style values and one icon path were adapted, and each is MIT licensed, so their notices are kept
here.

| Part of this plugin                                                                 | Adapted from                                                                                                                            |
| ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Month calendar: title, arrows, today dot, weekday headers, day cells, note dots     | [Calendar](https://github.com/liamcain/obsidian-calendar-plugin) and its [UI package](https://github.com/liamcain/obsidian-calendar-ui) |
| Day planner: controls, week strip, ruler, hour grid, time blocks, current-time line | [Day Planner](https://github.com/ivan-lednev/obsidian-day-planner)                                                                      |
| Day, week, month, quarter and year tabs over an inline calendar                     | [LifeOS](https://github.com/quanru/obsidian-lifeos) (layout idea only, no code copied)                                                  |
| Periodic note kinds, formats and commands                                           | [Periodic Notes](https://github.com/liamcain/obsidian-periodic-notes) (behavior only, no code copied)                                   |

The calendar arrows use the chevron path that the Calendar plugin ships, which is the Font Awesome
Free "chevron-left" icon, © Fonticons, Inc., licensed
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
